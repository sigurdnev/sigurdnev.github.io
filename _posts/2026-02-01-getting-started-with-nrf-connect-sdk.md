The fastest way to get productive with nRF Connect SDK is to standardize your local setup first.

## What to install

- nRF Connect for Desktop
- Toolchain Manager
- Visual Studio Code + nRF extensions

## First working build

1. Create a clean sample project.
2. Build for your board target.
3. Flash and verify serial output.

Once this loop works, your team can iterate quickly and debug real firmware issues instead of environment problems.
